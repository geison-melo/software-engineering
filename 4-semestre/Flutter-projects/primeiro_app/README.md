# MyNotes

Aplicativo Flutter para gerenciar anotações pessoais.

Projeto desenvolvido como atividade da disciplina de **Desenvolvimento de Dispositivos Móveis** — 4º semestre de Engenharia de Software.

## Tela Inicial

- Listagem das anotações com título e data de modificação
- Pop-up de confirmação ao clicar em uma anotação

## Como Executar

```bash
flutter run -d chrome
```
